# Klei Bridal Studio

A showcase and enquiry site for Klei Bridal Studio — a filterable gown catalogue, per-gown pages, favourites, an enquiry hand-off to chat, and a staff admin area, built with Next.js and deployed on the client's own Dokploy VPS.

Tracked in ORBIT as project **KBS**. See the project's team memory (`spec/*`, `decision/*`, `brief/requirements`) for the full specification.

## Developer handbook

Start at [`docs/handbook/README.md`](./docs/handbook/README.md) — the first document a new developer here should read. It is a faithful transcription of the eighteen approved sections carried on ORBIT issue `KBS-1` and its subtasks; the ORBIT pages remain the source of truth.
